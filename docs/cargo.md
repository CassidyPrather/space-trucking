# General Locations

All locations may include mail & packages intended for specific destinations.
E.g.
- SM_Item_Envelope_01
- SM_Prop_Package_01
- SM_Prop_Package_Pile_02

All non-mars planets import foods, but individual tastes may vary.
If a planet does not export water, they import it.

Show moons around the planets (not necessarily to scale)

Retcon: Delete mercury from the solar system. It is gone. Get rid of the night market and all that.

You can still try to sell stuff that isn't a planet's specific import, these are general valuation guidelines for economy tuning.

See game-prototypes project for Synty-mapping of food assets. There should be some flow-charts for some basic items in there. Can map those to the planets to an extent here
